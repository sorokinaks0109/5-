# Отчёт первой линейки (без Excel)

Три автономные HTML-страницы и общая папка с данными. Работает в Chromium без интернета и без установки:
страница получает доступ к выбранной папке через File System Access API.

```
Отчёт первой линейки/
  Помощник.html                    поручения, УПЦ, совещание, свод, письма, настройки (пароль)
  Директор.html                    только просмотр
  Страницы руководителей/
    Отчёт — <Фамилия>.html         руководитель заполняет свой отчёт (кто он — по имени файла)
  Данные/
    реестр.json                    пишет только помощник
    руководители/<Фамилия>.json    пишет только сам руководитель
    вложения/<Фамилия>/*.xlsx      таблицы руководителя
    архив/                         ежедневные копии
```

- `src2/lib/` — работа с папкой, модель (статусы, сроки, кто за что отчитывается, карта УПЦ), общий вид, подключение.
- `src2/apps/` — страницы помощника, руководителя, директора.
- `build.mjs` — собирает страницы (ExcelJS встраивается внутрь).
- `migrate.py` — перенос из старого общего отчёта и свежей карты УПЦ.
- `test/e2e.mjs` — сквозная проверка трёх страниц в Chromium.

```
npm i
python3 migrate.py старый_отчёт.xlsx карта_УПЦ.xlsx "out/Отчёт первой линейки"
node build.mjs "out/Отчёт первой линейки"
node test/e2e.mjs "out/Отчёт первой линейки" карта_УПЦ_изменённая.xlsx
```

Данные компании в репозиторий не кладём (`.gitignore`).
