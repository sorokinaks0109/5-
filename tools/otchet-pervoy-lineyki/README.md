# Сборщик отчёта первой линейки

Замена общему Excel-файлу «одна вкладка на руководителя». У каждого руководителя свой файл,
помощник ведёт Реестр, а `Сборщик.html` (работает в Chromium без интернета) рассылает поручения
по личным файлам, собирает статусы, показывает доклады на экране и сохраняет свод в Excel.

```
Отчёт первой линейки/
  Сборщик.html
  Реестр.xlsx          Мемо · План УПЦ · Руководители · Показатели УПЦ
  Руководители/        личные файлы (лист «Отчёт» + свои листы)
  Архив/               копии перед каждой рассылкой (создаётся сам)
  Своды/               своды для директора (создаётся сам)
```

- `src/core.js` — разбор реестра и личных файлов, сборка листа «Отчёт», контроль сроков, свод.
- `src/app.js`, `src/app.css` — интерфейс.
- `build.mjs` — собирает один автономный `Сборщик.html` (ExcelJS встраивается).
- `migrate.py` + `make-personal.mjs` — разовый перенос из старого общего файла.
- `test/e2e.mjs` — сквозная проверка в Chromium.

```
npm i
python3 migrate.py старый.xlsx "out/Отчёт первой линейки"
node make-personal.mjs "out/Отчёт первой линейки" out/migr.json
node build.mjs "out/Отчёт первой линейки/Сборщик.html"
node test/e2e.mjs "out/Отчёт первой линейки"
```

Данные компании в репозиторий не кладём: `*.xlsx` в `.gitignore`.
