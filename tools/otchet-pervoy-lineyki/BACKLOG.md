# План доработок

## На следующее обновление (неделя с 12.10.2026)

1. **Слияние правок, когда один отчёт заполняют несколько человек.**
   Сейчас отчёт сохраняется целиком: последний сохранивший перезаписывает правки предыдущего
   (и при сохранении в папку, и файлом). Нужно: при сохранении/приёме сравнивать с версией, от которой
   человек начал (база), и переносить только изменённые им поля — поручения, мероприятия, комментарии
   к показателям по отдельности, РОС/проекты целиком, если менялись. Дата «актуален на» — более поздняя.
   Пример: отчёт Хисматуллина заполняют сотрудники его офиса, в том числе Кондратьева М.В. (Тюмень, Windows).
2. **Оба способа на одной странице.** Страница со вшитыми данными («файлом») + кнопка
   «Сохранять сразу в папку» для тех, у кого Astra. Тогда отчёт, который заполняют люди на разных
   системах, — это одна страница.
3. **Версия для телефона директора** (iPhone, Outlook). Отдельный HTML-файл без скриптов
   (просмотрщик вложений в Outlook на iPhone скрипты не запускает): данные вписаны в файл,
   вёрстка под узкий экран, общая сводка сверху, блок «Просрочено и не выполнено»,
   руководители раскрываются нажатием (`<details>`), широкие таблицы листаются вбок, цвета статусов
   как на совещании. Запасной вариант — тот же отчёт в PDF, если почта не пропустит .html.
   Проверить: дойдёт ли вложение .html и как раскрываются блоки в Outlook на iPhone.
4. **Кнопка «Отправить отчёт директору»** на странице помощника: сохраняет версию для телефона
   и открывает новое письмо **в OWA** (веб-почта), а не в Р7 (сейчас `mailto:` открывает Р7 — почтовую
   программу по умолчанию). Через ссылку OWA можно заполнить адрес, тему и текст письма, а вложение
   так не прикрепить — файл перетаскивается в письмо вручную. Адрес OWA: `https://mail.gazprom-neft.ru/owa/`
   (Exchange на своих серверах; новое письмо — `…/owa/?path=/mail/action/compose&to=…&subject=…&body=…`,
   проверить на месте). Туда же перевести «Написать напоминание» и «Письмо директору».
5. **Страница руководителя открывается сразу с отчётом** (данные вписаны в файл), папка нужна
   только при «Сохранить». Ждём от Ксении: какая кнопка видна после перезапуска браузера
   («Продолжить с папкой» или только «Выбрать папку»), стоит ли «Удалять данные сайтов при закрытии»,
   версия Chromium (`chrome://version`).
6. **Комментарии соисполнителей.** Соисполнитель пишет свой комментарий по поручению прямо в своём отчёте.
   Ответственный видит все комментарии соисполнителей под поручением (и на экране совещания они
   собираются у ответственного). Статус поручения по-прежнему ставит ответственный.
7. **Одно поручение нескольким людям** (например, всей первой линейке): при добавлении — «выбрать
   нескольких / всех». Предложение: у каждого свой статус и пояснение, у поручения общий прогресс
   «выполнили 5 из 9»; снимается с контроля, когда выполнили все (или вручную).
   Согласовано с Ксенией: это не соисполнение — каждый получатель ответственный, у каждого свой статус.
8. **Приложения любых типов**, а не только Excel: PDF, картинки, Word, PowerPoint и др.
   Картинки показывать прямо в докладе; PDF — открывать во вкладке браузера; Word/PowerPoint браузер
   показать не может — значок файла и «Открыть / сохранить». В версию для директора и для телефона —
   картинки и список файлов. Ограничение размера одного файла (например, 20 МБ).
9. Ещё доработки по отчёту — Ксения пришлёт.

## Как обновлять без потери данных

Заменять только `.html` (Помощник, Директор, Для директора, Страницы руководителей, Проверка доступа).
Папку `Данные` не трогать. Перед заменой — копия папки `Данные`.
После обновления открыть Помощник: он сам перегенерирует страницы «файлом» и «Для директора».
