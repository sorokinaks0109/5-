# План доработок

## На следующее обновление (неделя с 12.10.2026)

1. **Слияние правок, когда один отчёт заполняют несколько человек.**
   Сейчас отчёт сохраняется целиком: последний сохранивший перезаписывает правки предыдущего
   (и при сохранении в папку, и файлом). Нужно: при сохранении/приёме сравнивать с версией, от которой
   человек начал (база), и переносить только изменённые им поля — поручения, мероприятия, комментарии
   к показателям по отдельности, РОС/проекты целиком, если менялись. Дата «актуален на» — более поздняя.
   Пример: отчёт Хисматуллина заполняют сотрудники его офиса, в том числе Кондратьева М.В. (Тюмень, Windows).
2. **Оба способа на одной странице.** Страница со вшитыми данными («файлом») + кнопка
   «Сохранять сразу в папку» для тех, у кого Astra. Тогда отчёт, который заполняют люди на разных
   системах, — это одна страница.
3. Доработки по самому отчёту — ждём список от Ксении.

## Как обновлять без потери данных

Заменять только `.html` (Помощник, Директор, Для директора, Страницы руководителей, Проверка доступа).
Папку `Данные` не трогать. Перед заменой — копия папки `Данные`.
После обновления открыть Помощник: он сам перегенерирует страницы «файлом» и «Для директора».
