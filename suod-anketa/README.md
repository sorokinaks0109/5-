# Повторный замер СУОД: анкета, сборщик, памятка

Готовые файлы лежат в папке `dist/`. Все три работают без интернета: открываются двойным щелчком в Edge, Chrome или Яндекс Браузере.

| Файл | Кому | Зачем |
|---|---|---|
| `Анкета_СУОД.html` | сотрудникам, вложением в письме | заполнить анкету и получить файл с ответами |
| `Сборщик_СУОД.html` | только организатору | собрать ответы и сравнить «до» и «после» |
| `Памятка_модели_поведения.html` | всем, на печать и на тренинги | памятка А4, карточки А6, мини-тест |

## Как проходит замер

1. **Рассылка.** Отправьте `Анкета_СУОД.html` вложением. В письме попросите **сохранить файл на компьютер и открыть двойным щелчком**: в окне предпросмотра Outlook анкета не работает.
2. **Заполнение.** Сотрудник выбирает дивизион и категорию, видит только свои вопросы и идёт по блокам. Ответы сохраняются сами, анкету можно закрыть и продолжить позже.
3. **Сохранение.** Кнопка «Сохранить ответы» скачивает файл вида `SUOD_Vostok_Ivanova_MS.csv` в «Загрузки». Сотрудник прикладывает его к ответному письму. Если файл не скачался, есть кнопка «Файл не скачался?»: она показывает текст, который можно вставить прямо в письмо.
4. **Профиль.** После сохранения сотрудник видит свой профиль по 7 блокам, подсказки по слабым блокам, модели поведения и мини-тест.

## Сборщик

- **Волна 1 (до).** Перетащите старые Excel-анкеты первого замера, сколько угодно сразу. Сборщик сам находит ФИО, категорию, дивизион (из заголовка «Дивизион "…"») и отметки «Х». Если остался только Excel-свод (лист со столбцом «ФИО» и процентами по блокам), подойдёт и он, но тогда сравнение будет только по блокам, без разбора по вопросам.
- **Волна 2 (после).** Перетащите все `.csv` из писем. Текст, вставленный в письмо вместо файла, добавляется кнопкой «Вставить текст из письма».
- Если сотрудник прислал анкету дважды, остаётся последняя загруженная.
- Что показывает: итог «до → после», блоки (столбики и паутина), таблицы по дивизионам и категориям (режимы «после / до / изменение»), каждый вопрос с разбивкой 0/3/5, сотрудников с личной динамикой, ответы своими словами.
- «Выгрузить в Excel» даёт файл `Svod_SUOD_<дата>.xlsx` с листами: Сводка, По дивизионам, По категориям, По вопросам, Сотрудники, Все ответы, Ответы своими словами, Изменения в анкете.
- Сборщик ничего не запоминает: после закрытия файлы нужно загрузить заново. Результат сохраняйте выгрузкой в Excel.

## Как считаются баллы

Так же, как в исходной Excel-анкете: варианты стоят 0, 3 и 5 баллов; % блока = средний балл по применимым вопросам / 5; итог = среднее по блокам. Вопросы 20–24 пропускаются, если в вопросе 19 ответ «нет СОП». Первая волна пересчитывается по тому же набору вопросов, что и вторая, иначе сравнение было бы нечестным.

## Что изменено в анкете по сравнению с первой волной

- Варианты ответа идут вперемешку, а не по возрастанию баллов. Насмешливые формулировки («всё совершенно, не надо изобретать велосипед», «цветные квадратики») заменены нейтральными. Цель — чтобы «правильный» ответ не угадывался. Побочный эффект: результат второй волны может немного просесть просто потому, что анкета стала честнее. Учитывайте это в выводах.
- **В21:** исправлены баллы, раньше более полный ответ стоил 0, а неполный 3. При загрузке первой волны баллы пересчитываются по исправленному ключу.
- **В22 + В23** объединены, потому что дублировали друг друга. В23 первой волны в расчёт не берётся.
- **В10** — опечатка «Не дает» → «Не даю». **В11** переформулирован. **В13, В15, В29** — закрыты пробелы в вариантах.

Полный список изменений показывается в сборщике и выгружается на лист «Изменения в анкете».

## Настройки

В начале файла `src/data.js` есть блок `CONFIG`:
- `divisions` — список дивизионов для выпадающего списка (сейчас там только «Восток», остальные можно вписать вручную через «Другой»);
- `sendTo` — кому отправлять файл (текст в конце анкеты);
- `levelHigh` / `levelMid` — границы уровней (80% и 50%).

После правок пересоберите файлы командой `python3 build.py`.

## Состав

- `src/data.js` — вопросы, блоки, модели поведения, подсказки, мини-тест (всё содержание в одном месте).
- `src/common.js`, `src/common.css` — общие функции и стили.
- `src/anketa.html`, `src/sborshik.html`, `src/pamyatka.html` — шаблоны страниц.
- `src/xlsx.mini.min.js` — библиотека SheetJS 0.18.5 (лицензия Apache 2.0) для чтения и записи Excel, встраивается в сборщик.
