# Серверная часть МурМемо: фото → тренажёр

Одна функция для **Yandex Cloud Functions** (`index.js`). Порядок работы с запросом:

1. **Лимит по адресу.** Считаются все фото с одного адреса, включая повторные (по умолчанию 40 в день).
   Это защита от перебора. Сам адрес не хранится, только его хеш.
2. **Распознавание текста** через Vision OCR.
3. **Готовый урок.** Если эту страницу уже кто-то фотографировал, урок отдаётся сразу: без нейросети,
   бесплатно и без учёта в лимите. Ребёнок ничего не выбирает, страница узнаётся по тексту.
   Два фото одной страницы распознаются чуть по-разному, поэтому сравниваются наборы слов:
   совпадение от 75 % считается той же страницей.
4. **Лимит на человека.** Новые страницы: по умолчанию 10 фото в день, сброс в полночь по Москве.
   Уже сфотографированные страницы открываются и после лимита.
5. **Нейросеть.** Основная модель — **YandexGPT Lite** (дешёвая). Если её ответ не разобрался или не прошёл
   проверку на выдумки, функция зовёт **YandexGPT Pro**. Если не справились обе, ребёнок видит понятную ошибку.
6. **Проверка на выдумки.** Строки стиха, имена, термины и годы, которых нет на фото, выбрасываются.
   Если нейросеть сильно присочинила, это считается неудачей (и Lite уступает место Pro).
7. Готовый урок **сохраняется**, чтобы следующий ребёнок с той же страницей получил его сразу.

Проверки без Яндекса (ответы и хранилище подменены): `node --test test.js` — 14 проверок.

## Как подключить (делает владелец аккаунта, ~30 минут)

**Ключ нигде не публикуйте и никому не пересылайте, в том числе в чат.** Он вводится только в консоли Яндекса.

1. Откройте [console.yandex.cloud](https://console.yandex.cloud), войдите через Яндекс ID.
   Создайте платёжный аккаунт (физлицо, карта). Новым пользователям обычно даётся стартовый грант.
2. Сразу поставьте ограничитель: **Биллинг → Бюджеты → Создать**, сумма 500 ₽, уведомления на 50 % и 100 %.
3. В каталоге `default` скопируйте его **идентификатор** (строка вида `b1g…`).
4. **Сервисные аккаунты → Создать**: имя `murmemo`, роли `ai.vision.user`, `ai.languageModels.user`
   и `storage.editor`.
5. Откройте этот аккаунт → **Создать новый ключ → API-ключ**. Скопируйте секрет: он показывается один раз.
6. **Object Storage → Создать бакет**: имя, например, `murmemo-lessons`, доступ **закрытый** (на чтение и список).
   В бакете **Жизненный цикл → Добавить правило**: префикс `limits/`, удалять объекты через 3 дня.
   Там лежат только дневные счётчики, хранить их дольше незачем.
7. **Cloud Functions → Создать функцию** `murmemo`, отметьте «Публичная функция».
   Создайте версию: среда **Node.js 22**, способ «Редактор кода», файл `index.js` — вставьте содержимое
   файла из этой папки, точка входа `index.handler`, таймаут 60 с, память 256 МБ,
   **сервисный аккаунт** — `murmemo` из шага 4 (через него функция пишет в бакет).
   Переменные окружения:
   - `YC_API_KEY` — секрет из шага 5;
   - `YC_FOLDER_ID` — идентификатор из шага 3;
   - `CACHE_BUCKET` — имя бакета из шага 6;
   - по желанию: `DAILY_PHOTOS` (по умолчанию 10), `DAILY_PHOTOS_IP` (по умолчанию 40),
     `YC_MODEL` (по умолчанию `yandexgpt-lite/latest`), `YC_MODEL_BACKUP` (по умолчанию `yandexgpt/latest`);
   - `ALLOWED_ORIGIN` — адрес сайта приложения, когда он появится.
8. Скопируйте **ссылку для вызова** функции (`https://functions.yandexcloud.net/…`) и передайте разработчику.
   Ссылка не секретная, ключ — секретный.

Без `CACHE_BUCKET` функция тоже работает, но готовые уроки и счётчики живут только в её памяти
и пропадают, когда функция «остывает». Для проверки сойдёт, для запуска нужен бакет.

## Запрос и ответ

```
POST <ссылка функции>
{ "images": ["<jpeg в base64>", ...], "clientId": "<случайный id устройства, 8–64 символа>" }
```

`clientId` приложение создаёт один раз и хранит на устройстве: это «человек» для дневного лимита.
Без него лимит считается по адресу.

Ответ: `{ "lesson": {...}, "cached": true|false, "model": "yandexgpt-lite/latest", "left": 7 }`,
где `cached` — урок взят готовым, `model` — какая модель собирала (нет, если урок готовый),
`left` — сколько новых фото осталось на сегодня.

Урок-стих:
```json
{ "kind": "poem", "title": "...", "author": "...", "translator": "...",
  "text": "строки через \n, строфы через пустую строку",
  "scenes": [{ "title": "...", "picture": "что нарисовать", "a": 0, "b": 7 }] }
```

Урок-параграф:
```json
{ "kind": "paragraph", "subject": "...", "title": "...",
  "persons": [{ "name": "...", "text": "..." }], "terms": [{ "term": "...", "text": "..." }],
  "events": [{ "year": 1612, "text": "..." }], "facts": [{ "text": "...", "false": "..." }],
  "questions": ["..."] }
```

Ошибки: `429` — лимит на сегодня, `422` — не получилось (нет текста на фото, модели не справились),
`400` — неверный запрос. Всегда `{ "error": "понятное объяснение" }`.

## Что проверено, а что нет

Проверено на подменённых ответах: разбор, проверка на выдумки, Lite → Pro, повторное использование
урока при чуть разном распознавании, лимиты (человек, адрес, смена дня по Москве).
**Не проверено на настоящем Яндексе**: форматы ответов OCR и YandexGPT и запись в Object Storage
по токену функции взяты из документации. Проверим первым же реальным фото после подключения.
