# Серверная часть «Учу играя»: фото → тренажёр

Одна функция для **Yandex Cloud Functions** (`index.js`). Что она делает:

1. принимает 1–4 фото страниц (JPEG в base64);
2. распознаёт текст через **Vision OCR**;
3. просит **YandexGPT** определить, стих это или параграф, и разложить материал для игр;
4. проверяет ответ: строки стиха, имена, термины и годы, которых нет на фото, выбрасываются.
   Если нейросеть сильно присочинила, функция честно отвечает ошибкой, а не выдаёт неверный тренажёр.

Проверки без Яндекса (ответы подменены): `node --test test.js`.

## Как подключить (делает владелец аккаунта, ~20 минут)

**Ключ нигде не публикуйте и никому не пересылайте, в том числе в чат.** Он вводится только в консоли Яндекса.

1. Откройте [console.yandex.cloud](https://console.yandex.cloud), войдите через Яндекс ID.
   Создайте платёжный аккаунт (физлицо, карта). Новым пользователям обычно даётся стартовый грант.
2. Сразу поставьте ограничитель: **Биллинг → Бюджеты → Создать**, сумма 500 ₽, уведомления на 50 % и 100 %.
3. В каталоге `default` скопируйте его **идентификатор** (строка вида `b1g…`).
4. **Сервисные аккаунты → Создать**: имя `uchu-igraya`, роли `ai.vision.user` и `ai.languageModels.user`.
5. Откройте этот аккаунт → **Создать новый ключ → API-ключ**. Скопируйте секрет: он показывается один раз.
6. **Cloud Functions → Создать функцию** `uchu-igraya`, отметьте «Публичная функция».
   Создайте версию: среда **Node.js 22**, способ «Редактор кода», файл `index.js` — вставьте содержимое
   файла из этой папки, точка входа `index.handler`, таймаут 60 с, память 256 МБ.
   Переменные окружения:
   - `YC_API_KEY` — секрет из шага 5;
   - `YC_FOLDER_ID` — идентификатор из шага 3;
   - `YC_MODEL` — `yandexgpt/latest` (точнее) или `yandexgpt-lite/latest` (дешевле);
   - `ALLOWED_ORIGIN` — адрес сайта приложения, когда он появится.
7. Скопируйте **ссылку для вызова** функции (`https://functions.yandexcloud.net/…`) и передайте разработчику.
   Ссылка не секретная, ключ — секретный.

## Запрос и ответ

```
POST <ссылка функции>
{ "images": ["<jpeg в base64>", ...] }
```

Стих:
```json
{ "lesson": { "kind": "poem", "title": "...", "author": "...", "translator": "...",
  "text": "строки через \n, строфы через пустую строку",
  "scenes": [{ "title": "...", "picture": "что нарисовать", "a": 0, "b": 7 }] } }
```

Параграф:
```json
{ "lesson": { "kind": "paragraph", "subject": "...", "title": "...",
  "persons": [{ "name": "...", "text": "..." }], "terms": [{ "term": "...", "text": "..." }],
  "events": [{ "year": 1612, "text": "..." }], "facts": [{ "text": "...", "false": "..." }],
  "questions": ["..."] } }
```

Ошибка — код 4xx и `{ "error": "понятное объяснение" }`.

## Что сделать до раздачи ссылки многим людям

Сейчас функция публичная: кто узнает её адрес, тот может её вызывать, а платите вы. Для проверки
на своей семье и знакомых этого хватает (плюс бюджет из шага 2). Перед широким запуском нужно добавить
ограничение числа запросов на человека.
