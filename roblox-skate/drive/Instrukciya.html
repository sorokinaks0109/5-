Skate Rush — полная инструкция

Версия игры: v6 (+ новые монеты, мега-трамплины, 3D-модели). Обновлено: 23 ноября 2026.

Здесь всё про игру Миланы: где лежит код, что куда вставлять, как публиковать, как настроены покупки и что осталось сделать. Эта инструкция и файлы в папке обновляются при каждом изменении игры.

2. Главное правило

Сама игра хранится в Roblox, а не в файлах. Открывайте её в Roblox Studio через File → Open from Roblox → Skate Rush. Файлы в этой папке нужны, чтобы обновлять отдельные скрипты.

Два скрипта не заменяйте целиком: Config и UI. В Config вписаны номера картинок, пассов и товаров, в UI исправлена кнопка X. Если их заменить файлом отсюда, номера картинок пропадут. Когда меняется что-то в этих скриптах, правку делаем одной строкой, и я пишу, какой именно.

После любой правки нажимайте Alt+P (File → Publish). Без этого игроки изменений не увидят.

Перед большими правками делайте копию: File → Download a Copy → сохранить на компьютер.

4. Как заменить скрипт новым кодом

  1. Остановите игру: красная кнопка Stop. Вкладок Client и Server вверху быть не должно (правки во время игры пропадают).
  2. Откройте нужный .txt из папки «Код» и скачайте его, или откройте на Диске и выделите весь текст: Ctrl+A, затем Ctrl+C.
  3. В Studio дважды щёлкните по нужному скрипту в Explorer.
  4. Нажмите Ctrl+A, затем Ctrl+V. Старый текст заменится новым.
  5. Нажмите Play и проверьте окно View → Output: красных строк быть не должно.
  6. Stop, затем Alt+P.

5. Открыть игру на другом компьютере

  1. Установите Roblox Studio и войдите в аккаунт MilaToCa3.
  2. Слева нажмите Experiences → Skate Rush. Откроется место «Место MilaToCa3: 11092026_1» — это и есть игра.
  3. Откроется последняя опубликованная версия. Всё, что не было опубликовано через Alt+P, на другом компьютере не появится.
  4. Карта видна только после нажатия Play: её строит скрипт.

6. Сохранение прогресса игроков

Уже включено. Если когда-нибудь появится красная надпись «Прогресс не сохраняется»: File → Experience Settings → Security → включить Enable Studio Access to API Services → Save.

7. Аниме-иконки на кнопках меню

Уже загружены и работают. Если нужно загрузить заново или добавить новые:

  1. Распакуйте архив SkateRush_icons.zip из папки «Картинки».
  2. В Studio: кнопка Assets → Import → выбрать картинки. Если всё не грузится сразу, грузите по 2–3 штуки.
  3. Картинки лежат в Asset Manager → Inventories → MilaToCa3. Правой кнопкой по картинке → Copy Asset ID.
  4. В Config найдите (Ctrl+F) Config.Icons и вставьте номер внутрь кавычек, вместе со словом rbxassetid://

Правильно: Daily = "rbxassetid://123456789",
Неправильно: Daily = rbxassetid://"123456789",

Номера, которые уже стоят в игре: Boards 105891710535274, Speed 72059436794814, Zones 127013820974134, Shop 113232226640587, Rebirth 79609621091334, Settings 130030156682767, Starter 112596472044584. Номера Daily, Gifts, Trails и Codes тоже вписаны, их можно посмотреть в Config в Studio.

10. 3D-модели

Уже загружены. Модели лежат в ReplicatedStorage → SkateAssets, и игра сама ставит их вместо простых фигур. Размер подгоняется автоматически.

  1. Кнопка Import с кубиком на верхней панели (не та, что в окне Terrain Editor!) или Ctrl+M → выбрать .glb → Import.
  2. Появившуюся модель перетащить в Explorer в папку SkateAssets.
  3. Назвать точно так, как в таблице.

12. Кто может играть

Сейчас игра открыта для игроков от 16 лет. Чтобы её видели дети младше 16, Roblox требует:

ШагСтатус
Подтверждение возраста автора✅ готово
Двухэтапная защита аккаунта (по почте)✅ готово
Анкета о содержании игры✅ готово
250 активных игроков ИЛИ залог 1 000 робуксов (возвратный)⏳ осталось

Где смотреть: create.roblox.com → Skate Rush → Publish settings → Manage audience. Перед оплатой залога прочитайте условия возврата в строке «Pay the Kids & Select publishing fee».

Как другим зайти в игру: откройте игру на roblox.com, скопируйте адрес из браузера (вида https://www.roblox.com/games/…/Skate-Rush) и отправьте. Аккаунт игрока должен пройти проверку возраста: Настройки → Информация об аккаунте → Подтвердить возраст.

13. Частые проблемы

Что видитеЧто делать
Кнопки серые (Publish, Experience Settings)Игра запущена. Нажмите Stop
Правки пропали после StopПравили во время игры. Правьте только при остановленной игре
Ошибка 256 «Failed to open send channel» при входеПроблема связи с серверами Roblox, не игры. Зайти ещё раз, включить или выключить VPN, попробовать мобильный интернет
Игру не видно в поискеНовые игры поиск почти не показывает. Заходите по прямой ссылке
Картинка на кнопке пустаяRoblox ещё проверяет картинку (подождать 10–15 минут) или номер записан не внутри кавычек
На сайте «[TITLE UNAVAILABLE]»В браузере вошли не в тот аккаунт. Войти в MilaToCa3
Красные строки в OutputСфотографировать окно Output и прислать Claude
На кнопке закрытия окна «(X)» со скобкамиСкрипт UI, строка 1014: внутри кавычек оставить только букву X
Нет следа за новой доскойСкрипт SkateClient: найти FindFirstChild("Deck") и дописать , true перед скобкой → FindFirstChild("Deck", true)

Трюки подряд дают комбо до x12. Не докрутил трюк до приземления — падение. Ворота в следующую зону зеленеют, когда хватает уровня и монет: въезжаешь, и они открываются.
