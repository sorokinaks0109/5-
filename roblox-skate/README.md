# 🛹 Skate Rush — скейт-симулятор для Roblox

Первая версия игры. Здесь уже есть всё, чтобы играть: карта из 6 зон, трюки, комбо, прокачка, доски, донат-магазин, ежедневные награды, коды и трюк-битвы между игроками.

---

## Как открыть игру (5 минут)

1. Скачай файл **`SkateRush.rbxlx`** из этой папки (на GitHub: открой файл → кнопка «Download raw file»).
2. Открой **Roblox Studio** → **File → Open from File** → выбери `SkateRush.rbxlx`.
3. Нажми **Play** (или F5).

> Пока игра не запущена, мир в Studio пустой — это нормально. Карту строит скрипт в момент запуска, поэтому её легко менять цифрами в настройках.

**Если что-то не работает:** открой окно **View → Output**. Красные строки — это ошибки. Скопируй их и отправь нейросети или мне — починим.

## Как играть

| Действие | Компьютер | Телефон |
|---|---|---|
| Ехать | WASD | джойстик |
| Прыжок | Пробел | кнопка прыжка |
| Кикфлип | **E** | ФЛИП |
| Спин 360 | **Q** | СПИН |
| Грэб | **R** | ГРЭБ |
| Бэкфлип | **F** | БЭК |

- **Трамплины** (со светящейся стрелкой) подбрасывают вверх. В воздухе делай трюки.
- **Не докрутил трюк до приземления — падаешь** и теряешь комбо.
- **Комбо**: трюки подряд растят множитель (x1.5, x2, x2.5…). Разные трюки дают больше, повтор того же трюка — вдвое меньше.
- Комбо засчитывается, когда проедешь по земле чуть больше секунды. Полоска под комбо показывает, сколько осталось.
- **Перила** — это грайнд: пока едешь по ним, комбо не заканчивается и копятся очки. Из-под доски летят искры.
- **Мега-трамплин** в середине каждой зоны — самый долгий полёт, можно успеть 3–4 трюка.
- **Звёзды** на карте дают монеты и появляются снова через 45 секунд.

## Что есть в игре

**Прогресс:**
- 6 зон: Двор → Неоновый город → Пляж → Ледяной каньон → Вулкан (с лавой!) → Космос (с низкой гравитацией). В каждой зоне свой свет, цвета и декор.
- Чтобы пройти в следующую зону, нужен уровень и монеты. Чем дальше зона, тем больше монет за трюки (до x16).
- Прокачка скорости (50 ступеней) и разгон как на настоящем скейте.
- 7 досок: у каждой своя скорость, прыжок и след. У огненной доски есть пламя, у галактической — искры.
- Перерождение: сбрасываешь монеты и скорость, но навсегда получаешь +50% монет.

**Чтобы игроки возвращались:**
- Ежедневная награда 7 дней подряд, растёт каждый день.
- Коды для соцсетей: `SKATE`, `KICKFLIP`, `RUSH2026`.
- **Трюк-битва** раз в 4 минуты: 75 секунд соревнования на сервере, первые три места получают монеты.
- Рекорд комбо, надписи «НОВЫЙ УРОВЕНЬ», «НОВЫЙ РЕКОРД».
- Подсказки для новичков в первые минуты игры.

**Донат (робуксы):**

| Товар | Тип | Советую цену |
|---|---|---|
| x2 монеты навсегда | геймпасс | 199 R$ |
| x3 монеты навсегда | геймпасс | 449 R$ |
| Золотая доска (+25% монет) | геймпасс | 299 R$ |
| Спасти комбо после падения | разовый | 5 R$ |
| Открыть следующую зону | разовый | 25 R$ |
| Буст x2 на 15 минут | разовый | 15 R$ |
| Мешок монет | разовый | 19 R$ |
| Сундук монет | разовый | 79 R$ |

Почему геймпассы дорогие: их покупают **один раз**, так что за 10 R$ ты бы потеряла почти все деньги. Дешёвыми должны быть разовые покупки, их берут много раз.

Кнопка «Вернуть за 5 R$» появляется после падения, только если потерянное комбо чего-то стоило. Магазин сам на игрока не выскакивает: детей, которых заваливают покупками, раздражает, и они уходят.

## Сохранение прогресса

Прогресс сохраняется сам. Чтобы это работало в Studio:

1. **File → Publish to Roblox** (опубликуй игру, можно приватно).
2. **Home → Game Settings → Security → Enable Studio Access to API Services** → включить.

Без этого игра работает, но после выхода всё сбрасывается, о чём в начале игры появится надпись.

---

## Как настроить донат

Пока ID товаров равны 0, **в Studio все покупки срабатывают бесплатно**, чтобы можно было всё проверить. В опубликованной игре такие товары не продаются.

1. Опубликуй игру (**File → Publish to Roblox**).
2. Зайди на **create.roblox.com** → твоя игра → **Monetization**.
3. **Passes** → создай 3 геймпасса (x2, x3, Золотая доска), поставь цены и включи продажу (**Item for sale**).
4. **Developer Products** → создай 5 товаров (Спасти комбо, Следующая зона, Буст, Мешок, Сундук).
5. Скопируй ID каждого товара и вставь в файл **ReplicatedStorage → SkateShared → Config** вместо нулей:

```lua
Coins2x = { id = 123456789, price = 199, ... },
```

6. Цена в поле `price` — только подпись на кнопке. Она должна совпадать с ценой на сайте.

## Как менять игру

**Почти всё меняется в одном файле — `Config`** (ReplicatedStorage → SkateShared → Config):

- цены зон, досок, скорости;
- очки за трюки и сколько они длятся;
- коды и награды;
- как часто идёт трюк-битва;
- цвета и свет каждой зоны.

Остальные скрипты:

| Скрипт | Что делает |
|---|---|
| `ServerScriptService → SkateServer` | монеты, сохранение, покупки, битвы |
| `SkateServer → World` | строит карту: трамплины, перила, декор |
| `SkateServer → Data` | сохранение прогресса |
| `StarterPlayerScripts → SkateClient` | управление скейтом, трюки, падения |
| `SkateClient → UI` | весь интерфейс |

Можно строить карту и руками поверх сгенерированной: всё, что не лежит в папке `SkateWorld`, скрипт не трогает. Чтобы руками построенный трамплин подбрасывал, добавь ему тег `Kicker` и атрибут `Power` = 80. Чтобы по детали можно было грайндить, добавь тег `Rail` и атрибут `Rail` = true.

## Что делать дальше, чтобы игра стала популярной

1. **Поиграй сама 30 минут и дай поиграть 3–5 друзьям.** Смотри молча, где им скучно, где непонятно и где они бросают. Это важнее любых новых функций.
2. **Иконка и обложка.** По ним игру выбирают в поиске. Яркий персонаж на скейте в прыжке, крупно, мало текста.
3. **Звуки и музыка.** Стук колёс, звук приземления, музыка в каждой зоне. Бесплатные звуки есть в Toolbox в Studio (вкладка Audio).
4. **Английский язык.** Сейчас весь текст на русском. Перевод на английский даст в разы больше игроков, потому что большинство игроков Roblox не говорят по-русски.
5. **Короткие видео в TikTok и YouTube Shorts.** Мега-трамплин и длинные комбо хорошо смотрятся на видео. Давай в конце код на монеты.
6. **Обновления раз в 1–2 недели:** новая зона, новая доска, новый трюк. Roblox продвигает игры, которые обновляются и в которые возвращаются.

**Идеи для следующих версий:** питомцы, которые бегают за скейтером; гонки на время; свой скейт-парк; таблица лучших игроков всего мира; новые трюки (мануал, импоссибл); анимации персонажа.

## Для продвинутых: Rojo

Код лежит в `src/` отдельными файлами, а `default.project.json` — проект для [Rojo](https://rojo.space). Это позволяет писать код в VS Code и сразу видеть изменения в Studio. Файл `SkateRush.rbxlx` собирается заново командой:

```
python3 build_place.py
```
