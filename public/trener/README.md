# Тренажёр по параграфу (черновик)

Игры по параграфу учебника. Сейчас материал — «Смутное время», история России, 7 класс —
записан вручную в начале `index.html` (объект `LESSON`). Позже такой же набор будет собирать
нейросеть Яндекса по фото страниц.

Игры:
- **Соедини** — деятель и что он сделал (по 5 пар за раунд);
- **Мемори** — термин и его значение (по 4 пары за раунд);
- **Лента времени** — событие ставится на свой год;
- **Карта Смуты** — сначала подписать города на схеме, потом найти, где что было.

Один файл без сборки и без сервера: откройте `index.html` в браузере. Лучшие результаты (звёзды)
хранятся в браузере.
