# Учу играя (черновик)

Тренажёры по школьным урокам. Один файл `index.html`, без сборки и без сервера: откройте его в браузере.
Уроки пока записаны вручную в начале скрипта (объекты `HISTORY` и `POEM`). Потом такой же набор
будет собирать нейросеть Яндекса по фото страниц учебника.

**История: «Смутное время», 7 класс** — четыре игры:
- **Соедини** — деятель и что он сделал (по 5 пар за раунд);
- **Мемори** — термин и его значение; карточки терминов и значений разного цвета,
  неверная пара остаётся открытой, пока ребёнок сам не нажмёт;
- **Лента времени** — событие ставится на свой год;
- **Карта Смуты** — подписать города на схеме, потом найти, где что было.

**Литература: «Перчатка» Шиллера, перевод Жуковского** — отрывок выбирается нажатием
на первую и последнюю строку, дальше пять шагов: исчезающий текст → собери строку →
что дальше? → пропущенное слово → расскажи наизусть.

Очки, серия правильных ответов, звук (выключается кнопкой), конфетти на итоге.
Лучшие результаты, выбранный отрывок и настройка звука хранятся в браузере.
