# Мурфография (старый адрес)

Основной адрес приложения — **https://murfografia.ru**, код — в репозитории
[sorokinaks0109/murfografia](https://github.com/sorokinaks0109/murfografia).

Здесь лежит копия того же приложения, чтобы старая ссылка продолжала работать. Как только
https://murfografia.ru отвечает с защищённым соединением, приложение само переводит ребёнка
туда — в первый раз вместе с прогрессом (ссылкой `#import=…`). Копировать сюда новые версии
больше не обязательно.
