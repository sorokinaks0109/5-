# Мурфография переехала

Приложение теперь живёт в репозитории [murfografia](https://github.com/sorokinaks0109/murfografia)
и открывается по адресу **https://murfografia.ru**.

Здесь осталась только страница «Мы переехали»: она переносит прогресс ребёнка на новый адрес
ссылкой `https://murfografia.ru/#import=…` и через 3 секунды открывает новый сайт.
`sw.js` удаляет старый кэш словарика и отключается.
