# Тренинг по ИСМ: презентация с интерактивными упражнениями

## Как пользоваться

1. Скопируйте на ноутбук всю папку целиком: файл `Тренинг_ИСМ_интерактив.pptx` и рядом папку `uprazhneniya`.
2. Откройте презентацию в режиме показа. На слайдах с заданиями есть оранжевая кнопка **▶ ИНТЕРАКТИВ**: по клику упражнение откроется в браузере.
3. Закончили упражнение — закройте окно браузера и вернитесь в презентацию.

Интернет не нужен. Все упражнения собраны в меню: `uprazhneniya/index.html`.

| 4 | Область применения |
| 12 | Типы процессов |
| 14 | Среда организации |
| 17 | Заинтересованные стороны |
| 27 | Записи |
| 31 | Риск или не риск? |

## Как поменять тексты заданий

Все карточки, вопросы и пояснения лежат в `build.py`, в списке `EXERCISES`. Поменяйте текст и запустите:

```
python3 build.py
python3 add_buttons.py исходная.pptx Тренинг_ИСМ_интерактив.pptx
```

Вторая команда нужна, только если поменялись номера слайдов.
