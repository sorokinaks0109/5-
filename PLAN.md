# План проекта «Идейные игры — Пять вершин»

## Цель
Веб-приложение для онлайн-отборочного тура конкурса «Идейные игры» (юбилейный, 5 лет).
Каждый участник — альпинист, проходит 5 вершин-этапов, набирает высоту (до 5000 м).

## Архитектура одной картинкой

```
content/content.json          ← все задания, тексты, настройки (правит организатор)
        │
        ├──► src/core/*        ← игровая логика на чистом TypeScript (без React и без базы):
        │                        выдача заданий, перемешивание, проверка, баллы, таймер,
        │                        подсказки, рейтинг. Один код и для демо, и для сервера.
        │
        ├──► демо-режим:       src/core + хранилище в браузере (localStorage)
        │
        └──► боевой режим:     Supabase Edge Function «game» (тот же src/core)
                               + таблицы Postgres с защитой строк (RLS)
                               + вход Supabase Auth по личному коду

Фронтенд (React + Vite + TS) общается только через интерфейс Api:
  - DemoApi      → вызывает src/core прямо в браузере;
  - SupabaseApi  → вызывает функцию game на сервере.
```

Правильные ответы в боевом режиме никогда не попадают в браузер:
- в сборку фронтенда попадает только «публичная» часть content.json (тексты, названия, настройки) —
  это делает плагин Vite `virtual:public-content`;
- полный content.json вшивается в серверную функцию при публикации.

## Структура

```
content/content.json                 банк заданий и настройки
public/images/stage2/*.svg           картинки склада для этапа 2 (заменяемые)
src/core/                            игровая логика (тестируется vitest)
  types.ts                           типы данных
  random.ts                          сидируемый генератор, перемешивание, выборка
  content.ts                         проверка content.json, публичная часть
  assign.ts                          случайная выдача заданий участнику
  items.ts                           сборка заданий, публичный вид, проверка ответа
  scoring.ts                         баллы, подсказки, погода, распределение метров
  timer.ts                           таймер этапа («кислород»)
  ranking.ts                         рейтинг и тай-брейк
  codes.ts                           генерация личных кодов
  service.ts                         GameService — все правила игры
  dispatch.ts                        единая точка входа «действие → метод сервиса»
  memoryStore.ts                     хранилище в памяти / localStorage
  demoSeed.ts                        наполнение демо ботами
src/api/                             DemoApi и SupabaseApi
src/components/                      гора, баллон, погода, значок «5 лет», снег…
src/screens/                         вход, профиль, главная, этапы, рейтинг, жюри, организатор
src/lib/                             выгрузка CSV/XLSX, сертификат PNG
supabase/schema.sql                  таблицы, RLS-политики
supabase/functions/game/             серверная функция
.github/workflows/                   публикация на GitHub Pages и функции в Supabase
tests/                               тесты
```

## Баллы (метры)
| Вершина | Что проверяется | Метры |
|---|---|---|
| 1 Зоркий глаз | 10 ситуаций × 100 м | 1000 |
| 2 Порядок в лагере | порядок 5С 250 + нарушения на картинке 450 + сопоставление 300 | 1000 |
| 3 Тропа потока | порядок операций 300 + операции без ценности 400 + расчёт 300 | 1000 |
| 4 Разбор завала | «5 почему» 300 + корневая причина 150 + меры 150 + 4 вопроса × 100 | 1000 |
| 5 Юбилейная | жюри: 5 критериев × до 200 м, среднее трёх судей | 1000 |

Подсказка («снаряжение») снижает метры за задание на 30 %. Всего 3 на тур.
