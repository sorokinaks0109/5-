# Мастерская сказок: конвейер персональных мультфильмов

## Бот-помощник (основной способ работы)

`bot.py` — Telegram-бот, который ведёт заказ по шагам: анкета → фото → персонаж →
согласование с родителем → 7 кадров → 6 клипов → озвучка → готовый ролик.
На каждом шаге бот присылает нужные кадры файлами и промпт, который копируется
одним нажатием. Результаты из Syntx просто пересылаешь боту.

Запуск на компьютере:
1. Установить Python 3.11+ (python.org, при установке отметить «Add to PATH»)
   и ffmpeg (Windows: `winget install Gyan.FFmpeg`, Mac: `brew install ffmpeg`).
2. Создать бота у @BotFather (`/newbot`) и получить токен.
3. Запустить `zapusk_windows.bat` (или `zapusk_mac.command`). При первом запуске
   откроется файл `.env`: вписать `BOT_TOKEN`, сохранить, запустить снова.
4. Написать боту `/start` — он покажет твой ID. Вписать его в `RAZRESHENO` в `.env`,
   перезапустить. Готово.

Бот работает, пока открыто окно запуска. Для работы 24/7 его переносят на сервер.

Команды: `/new` — новый заказ, `/gde` — что сейчас нужно сделать,
`/zakazy` — список заказов, `/sobrat` — собрать ролик, `/muzyka` — общая музыка сказки.

Если файл попал не в ту сцену — кнопка «📍 Это другая сцена». Можно подписать
файл номером сцены («06», «08 конец»), тогда он сразу ляжет куда нужно.

## Ручной режим (без бота)

Полуавтомат: картинки и оживление делаются вручную в Syntx (у него нет API),
а промпты под ребёнка и склейка ролика — автоматически.

## Как устроен шаблон

`shablony/chasy-deda-moroza/shablon.json` — сказка «Часы Деда Мороза», 35 секунд, 9 сцен.

| № | Сцена | Тип | Длительность |
|---|---|---|---|
| 01 | Дед Мороз у часов | общая | 2,8 с |
| 02 | Часы остановились | общая | 2,2 с |
| 03 | Лисёнок открывает книгу | общая | 3,4 с |
| 04 | Портрет ребёнка в книге | личная | 6,0 с |
| 05 | Вихрь: ребёнок появляется | личная | 6,0 с |
| 06 | Все у потухших часов | личная | 6,0 с |
| 07 | Касание часов | личная | 2,9 с (с 0,04 с клипа) |
| 08 | Часы засияли, Новый год | личная | 2,9 с (с 3,2 с клипа) |
| 09 | Объятия и салют | личная | 3,0 с (с 3,0 с клипа) |

Общие сцены одинаковы для всех детей и лежат в `obshchie/`.
Под каждого ребёнка делаются только 6 личных сцен.

Опорные кадры сцен лежат в `kadry/`. Видео, кадры и заказы в git не попадают
(см. `.gitignore`): в них лица детей.

## Порядок работы с заказом

1. Создать папку `zakazy/<имя>/` и в ней `zakaz.json`:
   ```json
   {"imya": "Миша", "pol": "malchik", "vozrast": 5,
    "volosy": "тёмно-русые короткие", "glaza": "карие", "ochki": ""}
   ```
2. Получить карточку с готовыми промптами:
   ```
   python3 kartochka.py shablony/chasy-deda-moroza zakazy/<имя>
   ```
3. По карточке сделать в Syntx персонажа, 6 кадров и 6 клипов. Клипы положить
   в `zakazy/<имя>/klipy/04.mp4 … 09.mp4`. Озвучку по тексту из карточки сделать
   в Syntx (клонирование голоса, всегда один и тот же голос) и сохранить как
   `zakazy/<имя>/ozvuchka.mp3`. Музыку, если она отдельно, — `muzyka.mp3`.
4. Собрать ролик:
   ```
   python3 sobrat.py shablony/chasy-deda-moroza zakazy/<имя>
   ```
   Результат: `zakazy/<имя>/gotovyy_multfilm.mp4`, громкость выровнена до −14 LUFS.

Если какого-то клипа нет или он короче нужного, программа скажет, какой сцены не хватает.

Нужны Python 3 и ffmpeg.
