# Тренинг «8 шагов решения проблем: инструменты бережливого производства»

ООО «Газпромнефть-Снабжение», блок программ по операционной эффективности. Тренеры: Диана Овчаренко, Ксения Сорокина. 90 минут, онлайн.

## Перед тренингом

Для проведения нужны только три файла:

- `Тренинг_8_шагов.html`: вся презентация, упражнения, логотип и картинки в одном файле. Интернет не нужен.
- `Сценарий_тренинга_8_шагов.docx`: речь тренеров по слайдам и ответы к упражнениям.
- `Свод_чек-листа_до_после.xlsx`: анкета до и после.

Для участников после тренинга: `pamyatka-8shagov.pdf` (5 листов А4, есть HTML-версия `pamyatka-8shagov.html`).

1. Создайте анкету в Oprosso по инструкции на первом листе `Свод_чек-листа_до_после.xlsx`.
2. Ссылка на анкету уже вписана. Если она другая: откройте `Тренинг_8_шагов.html` в Блокноте, в самом начале найдите строку `anketa_do`, замените ссылку между кавычками (и в `anketa_posle`) и сохраните. QR-код на слайдах 2 и 41 построится сам.
3. Откройте `Тренинг_8_шагов.html` в Chrome, Яндекс Браузере или Edge. F — полный экран.

Управление: → / пробел / щелчок — дальше, ← — назад, M — список слайдов, F — полный экран. На слайдах-упражнениях дальше — кнопка ▶ внизу или PageDown.

## После тренинга

Выгрузите ответы из Oprosso и вставьте их на лист «Ответы» файла `Свод_чек-листа_до_после.xlsx`. На листах «Свод» и «По вопросам» появятся результаты каждого сотрудника до и после, прирост и график по вопросам. Формулы обычные, без макросов: файл работает в Excel и Р7-Офисе.

## Как поменять тексты

Исходники в папке `istochniki` (нужен Python 3, для сценария ещё pandoc):

- упражнения — `data.py`, затем `python3 build.py`;
- слайды — `slides.html`, затем `python3 make_single.py` (собирает один файл; картинки из папки `kartinki`);
- картинки — `kartinki/spisok.json`, затем `kartinki/generirovat.py` в окружении с ключом fal.ai;
- сценарий — `scenarij.md`, затем `python3 make_doc.py`;
- свод — `make_xlsx.py`.
