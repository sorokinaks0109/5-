# Тренинг «8 шагов решения проблем: инструменты бережливого производства»

ООО «Газпромнефть-Снабжение», блок программ по операционной эффективности. Тренеры: Диана Овчаренко, Ксения Сорокина. 90 минут, онлайн.

## Перед тренингом

1. Распакуйте архив целиком. Рядом должны лежать `Тренинг_8_шагов.html`, `nastroiki.js`, папки `uprazhneniya` и `slaidy`.
2. Создайте анкету в Oprosso по инструкции на первом листе `Свод_чек-листа_до_после.xlsx`. Тексты вопросов и вариантов берите с листа «Ключ» без изменений.
3. Откройте `nastroiki.js` в Блокноте, вставьте ссылку на анкету между кавычками в строке `anketa_do` и сохраните. QR-код на слайдах 2 и 33 построится сам, интернет для этого не нужен.
4. Откройте `Тренинг_8_шагов.html` в Chrome, Яндекс Браузере или Edge. F — полный экран.

Управление: → / пробел / щелчок — дальше, ← — назад, M — список слайдов, F — полный экран. На слайдах-упражнениях дальше — кнопка ▶ внизу или PageDown.

## После тренинга

Выгрузите ответы из Oprosso и вставьте их на лист «Ответы» файла `Свод_чек-листа_до_после.xlsx`. На листах «Свод» и «По вопросам» появятся результаты каждого сотрудника до и после, прирост и график по вопросам. Формулы обычные, без макросов: файл работает в Excel и Р7-Офисе.

## Как поменять тексты

Исходники в папке `istochniki` (нужен Python 3, для сценария ещё pandoc):

- упражнения — `data.py`, затем `python3 build.py`;
- слайды — `slides.html`, затем `python3 make_deck.py`;
- сценарий — `scenarij.md`, затем `python3 make_doc.py`;
- свод — `make_xlsx.py`.
